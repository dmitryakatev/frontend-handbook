# Классы

Классы — это механизм объектно-ориентированного программирования (ООП), позволяющий описывать сущности через свойства и методы.

В JavaScript классы появились в стандарте ES6, однако важно понимать, что они не являются отдельной моделью объектов, как в Java или C#.

Класс в JavaScript — это **синтаксический сахар над прототипным наследованием**.

## Основные принципы ООП

- инкапсуляция;
- наследование;
- полиморфизм.

## Что происходит при объявлении класса

### Пример

```js
class User {
  constructor(name) {
    this.name = name;
  }

  sayHello() {
    console.log(this.name);
  }
}
```

После объявления класса происходит несколько действий:

- создается функция-конструктор `User`;
- создается объект `User.prototype`;
- все методы класса помещаются в `User.prototype`;
- при создании экземпляра через `new` внутреннее свойство `[[Prototype]]` начинает ссылаться на `User.prototype`.

Именно поэтому методы существуют в одном экземпляре и разделяются всеми объектами класса.

## Где хранятся свойства и методы

Необходимо различать свойства экземпляра и методы класса.

### Свойства экземпляра

```js
const user = new User("Alex");
```

После создания объекта:

```
user
├── name
└── age
```

Свойства находятся непосредственно внутри объекта.

### Методы

```
User.prototype
├── sayHello()
├── logout()
└── changePassword()
```

Методы располагаются в `User.prototype`, поэтому используются всеми экземплярами класса.

## Цепочка прототипов

При обращении к свойству JavaScript ищет его последовательно по цепочке прототипов.

### Пример

```js
user.sayHello();
```

Поиск выполняется следующим образом:

```
user
↓
User.prototype
↓
Object.prototype
↓
null
```

Как только свойство найдено — поиск прекращается.

Если свойство отсутствует во всей цепочке, результатом будет `undefined`.

## Наследование

Класс может наследоваться от другого класса с помощью `extends`.

### Пример

```js
class Animal {}

class Dog extends Animal {}
```

При этом создаются две связанные цепочки.

### Экземпляры

```
dog
↓
Dog.prototype
↓
Animal.prototype
↓
Object.prototype
↓
null
```

### Конструкторы

```
Dog
↓
Animal
↓
Function.prototype
```

## constructor, super и this

Если дочерний класс объявляет собственный конструктор, необходимо вызвать `super()`.

### Пример

```js
class Dog extends Animal {
  constructor(name) {
    super(name);

    this.name = name;
  }
}
```

До вызова `super()` обращаться к `this` нельзя.

До этого момента объект еще не инициализирован, поэтому попытка обращения приведет к ошибке.

## super

`super` можно использовать не только в конструкторе.

Он позволяет обращаться к реализации родительского класса.

### Пример

```js
class Animal {
  speak() {
    console.log("...");
  }
}

class Dog extends Animal {
  speak() {
    super.speak();
    console.log("Woof");
  }
}
```

## Статические методы

Статические методы принадлежат самому классу, а не его экземплярам.

### Пример

```js
class MathUtils {
  static sum(a, b) {
    return a + b;
  }
}

MathUtils.sum(1, 2);
```

Экземплярам класса статические методы недоступны.

## Геттеры и сеттеры

JavaScript позволяет описывать свойства через специальные методы.

### Пример

```js
class User {
  get fullName() {
    return this.name;
  }

  set fullName(value) {
    this.name = value;
  }
}
```

Внешне они выглядят как обычные свойства.

## Приватные поля

Современный JavaScript поддерживает приватные поля через символ `#`.

### Пример

```js
class User {
  #password;

  constructor(password) {
    this.#password = password;
  }
}
```

Обращаться к таким полям извне невозможно.

## Что находится в prototype

Когда выполняется:

```js
User.prototype.sayHello = function () {};
```

мы не заменяем прототип, а добавляем новое свойство в существующий объект.

Все существующие экземпляры сразу начинают видеть новый метод.

Если выполнить:

```js
User.prototype = {};
```

происходит замена всего объекта прототипа.

После этого:

- новые экземпляры будут ссылаться на новый объект;
- старые экземпляры продолжат ссылаться на прежний объект.

Это две принципиально разные операции.

## Модификаторы доступа (TypeScript)

TypeScript поддерживает модификаторы доступа.

### public

- доступен отовсюду;
- используется по умолчанию.

### protected

- доступен внутри класса и его наследников;
- недоступен извне.

### private

- доступен только внутри самого класса;
- недоступен даже наследникам.

## Абстрактные классы (TypeScript)

Абстрактный класс нельзя создать через `new`.

Он используется как базовый шаблон.

### Пример

```ts
abstract class Animal {
  abstract speak(): void;
}
```

Все наследники обязаны реализовать абстрактные методы.

## Частые ошибки

❌ Считать, что методы копируются в каждый экземпляр.

Методы находятся в `prototype` и используются всеми экземплярами.

---

❌ Считать, что класс — отдельный механизм JavaScript.

Класс является синтаксическим сахаром над прототипным наследованием.

---

❌ Путать `prototype` и `[[Prototype]]` (`__proto__`).

`prototype` — свойство функции-конструктора.

`[[Prototype]]` — ссылка конкретного объекта на его прототип.

---

❌ Считать, что `User.prototype.foo = ...` и `User.prototype = {}` делают одно и то же.

`User.prototype.foo = ...` изменяет существующий объект прототипа.

`User.prototype = {}` полностью заменяет объект прототипа.
